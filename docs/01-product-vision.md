# Product Vision

## Vision

Build a local personal AI desktop assistant that helps the user work faster on a Windows PC. It should combine local chat, file understanding, document generation, safe PC automation, and project organization.

The assistant should feel like a practical local command center, not a toy chatbot.

## Target User

The first target user is the owner of this PC:

- Student
- Developer or coding learner
- Project builder
- Uses Windows
- Wants local/private AI help
- Wants automation without paid APIs
- Has 16GB RAM and integrated graphics

## Primary Jobs

1. Chat locally.
2. Help explain and debug code.
3. Analyze selected documents and notes.
4. Help create study notes and summaries.
5. Generate proposals, reports, and writeups.
6. Open selected apps, folders, and projects.
7. Save chat history locally.
8. Organize project context.
9. Later, support voice, file search, and folder/project analysis.

## Personality

The assistant should be:

- Useful
- Calm
- Direct
- Local-first
- Safe with user files
- Transparent when taking actions
- Good at asking before risky operations

## Experience Goals

The user should be able to say:

- "Open my school folder."
- "Summarize this PDF."
- "Explain this error."
- "Create a report from these notes."
- "Save this as a project proposal."
- "Find files about networking in my study folder."
- "Open VS Code and my backend project."

## Product Boundaries

The assistant should not:

- Secretly scan private folders.
- Delete or overwrite files without confirmation.
- Run arbitrary PowerShell commands from model output.
- Depend on paid APIs for core features.
- Require a powerful gaming GPU.
